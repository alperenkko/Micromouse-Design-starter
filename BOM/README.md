# Bill of Materials (BOM)

This folder contains the complete Bill of Materials for the Micromouse project.

### File Descriptions:
* **`BOM.csv`**: Main component list including the processor board, gyroscope/IMU, wheels, and core hardware. *(Required for the grant request)*.
* **`BOM_ozdisan.csv`**: Component list for the custom-designed IR sensor module (featuring analog voltage output, ambient light protection, and noise filtering).
* **`BOM_ozdisan.pdf`**: Local supplier quotation in Turkish Lira (TRY) for the IR sensor parts, including a $5 shipping estimation.
